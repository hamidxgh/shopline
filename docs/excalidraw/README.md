# Excalidraw templates

## `system-architecture-template.excalidraw`

Lifetime spine for any system (Shopline-shaped).

### Open

1. Go to [excalidraw.com](https://excalidraw.com)
2. Menu → Open → pick `system-architecture-template.excalidraw`
3. Duplicate immediately (Save as / export) before editing

Or in VS Code / Cursor: Excalidraw extension → open the file.

### How to use (8 minutes)

1. Rename the title to your system
2. Keep the five zones: Edge → App → Data → Async → Cross-cutting
3. Delete any box you cannot name a **pain** for
4. Trace **one** request (browse OR checkout, not both on day one)
5. Solid arrows = write / sync; dashed = read / stale copies / async fan-out
6. Side systems stay on the bottom strip

### Lifetime rule

Pain first. Tool second. If there is no pain, erase the box.
